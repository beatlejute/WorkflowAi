# Данные ревью по пунктам prose и visual

Пункт DoD с записью `prose` или `visual` тикета с `dod_format: 2` пайплайн сам не закрывает: пункт становится вопросом модели стадии ревью. Модель судит только по данным, которые собирает пайплайн, — они перечислены ниже. Тикет без `dod_format: 2` проверяет агент ревью по файлу тикета, раздел «Результат выполнения» он читает, и этот справочник к нему не относится. Правило — узел P4R1, отметка пунктов — узел P3R2.

## Что видит модель

| Данные | Откуда берутся | Что делает исполнитель |
|---|---|---|
| Вопрос | Полный текст строки пункта DoD. Причина записи `prose` в вопрос не входит, у `visual` добавляются пути изображений | В строку пункта не дописывает ни пометок, ни пояснений: они станут частью вопроса |
| Вывод записей `check` | Команды пунктов с `check` этого тикета, запущенные пайплайном | — |
| Дифф | Файлы из подраздела «Изменённые файлы», только строки-буллеты с путём в обратных кавычках: «- `путь` — что изменено». Длинный дифф усекается с пометкой | Каждый файл — отдельной строкой, путь от корня проекта |
| Фрагменты исходника | Каждая ссылка `путь:строка` или `путь:строка-строка` в разделе «Результат выполнения» даёт строки файла ±5 с номерами. Путь — от корня проекта, к файлу с расширением, внутри проекта | Ставит ссылку на код или тест, который показывает каждую часть пункта |
| Изображения | Файлы по путям записей `visual` | Кладёт снимок результата по пути записи (узел P3R7) |

## Чего модель не видит

- Текста раздела «Результат выполнения»: обоснований, пересказа, вставленного диффа, вывода команд, таблиц замеров.
- Причины записи `prose`.
- Файлов, которых нет в «Изменённых файлах» строкой с путём в обратных кавычках. Строка вида «- путь — что изменено» без кавычек не читается.

Комментарии-заглушки шаблона тикета из «Изменённых файлов» удаляют: 2026-09-29 закомментированный пример пути провалил проверку артефактов как заявленный, но отсутствующий файл.

## Как отвечать на отказ ревью

| Что случилось | Ответ |
|---|---|
| Часть пункта не видна в данных | Ссылка `путь:строка` на код или тест, который её показывает. Такого кода или теста нет — правка кода или теста |
| Файл не попал в дифф | Строка «- `путь` — что изменено» в «Изменённых файлах» |
| Модель нашла дефект | Правка кода или теста, а не абзац в Result |
| Свойство не видно ни в коде, ни в изображении и не доказывается записью `check` пункта (размер, число, внешнее требование) | Файлов вне scope не создавать. Свойство — в «Заметки», `status: blocked` с причиной «свойство пункта N не доказуемо записью DoD» |

Пример ссылки в «Что сделано»: «сброс кэша маршрутов — `src/cache.ts:40-44`, тест — `test/cache.test.ts:12`».

Инцидент 2026-09-29–30: 6–8 платных повторов после отказа ревью связаны с незнанием этих данных — обоснования, дифф и замеры в Result, строки «Изменённых файлов» без обратных кавычек, ссылки `путь:строка`, дописанные только после отказа.
