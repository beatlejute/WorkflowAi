# Шаблон: Result

Заполняется исполнителем по ходу и после выполнения задачи. Секция `## Результат выполнения` обычно уже есть в тикете из шаблона тикета: заполни её этими подсекциями (резюме — в `### Что сделано` или в `### Summary` шаблона), удали комментарии-заглушки шаблона и вторую секцию не создавай; секции нет — создай по образцу ниже.

```markdown
## Результат выполнения

### Что сделано
- {описание выполненной работы по каждому пункту DoD, evidence со ссылками `путь:строка` на код и тесты}

### Изменённые файлы
- `{путь/от/корня/проекта}` — {что изменено}
- `{путь/от/корня/проекта}` — {что создано}

### Найденные дефекты
- {нет — или по строке на расхождение: что ожидалось → что наблюдается, где видно: `путь:строка`, вывод команды, текст ошибки}

### Заметки
- {прочитанные модули `.workflow/shared/` или «shared нет»; контекст для связанных задач, рекомендация для следующего плана, обоснования решений; утверждение о числе, свойстве файла, поведении кода или причине сбоя — с первоисточником или с пометкой «предположение»}
```

## Правила заполнения

| Поле | Обязательно | Что писать |
|------|-------------|------------|
| `### Что сделано` | **Да** | Конкретные действия, evidence по каждому пункту DoD со ссылками `путь:строка` на код и тесты: у пунктов `prose` и `visual` тикета с `dod_format: 2` модель ревью видит фрагменты по ссылкам, а не текст Result. Не шаблонный текст |
| `### Изменённые файлы` | **Да** (если DoD требует изменений) | Каждый созданный или изменённый файл отдельной строкой «- `путь` — что изменено», путь от корня проекта в обратных кавычках: по этим строкам пайплайн проверяет существование файлов и строит дифф для ревью. Только существующие файлы: переименованный — новым путём, удалённый — в «Заметках» |
| `### Найденные дефекты` | **Да** | «нет» или по строке на каждое расхождение с ожиданием: что ожидалось, что наблюдается, где видно. По этому заголовку стадия разбора плана находит дефекты, поэтому рекомендаций и заметок здесь нет |
| `### Заметки` | **Да** | Прочитанные модули `.workflow/shared/` или «shared нет»; блокеры, контекст и рекомендация для следующих задач; утверждения о фактах вне правки — с первоисточником (`путь:строка`, команда, текст ошибки) или с пометкой «предположение» |
| Время, модель, агент исполнения | Не пишутся | Их записывает пайплайн (frontmatter, `## История работы`); подсекцию шаблона тикета с этими полями удали |
