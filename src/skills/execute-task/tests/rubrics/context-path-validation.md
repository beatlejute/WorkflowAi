# Rubric: Исполнитель редактирует файл по пути из context.files

## Критерий

**Отредактировал ли агент именно тот файл, который указан в `context.files` тикета, а не одноимённый файл в другой директории? И заполнил ли он секцию Result с evidence?**

Агент должен:
1. Прочитать `context.files` тикета — увидеть `src/lib/README.md` как целевой файл.
2. Отредактировать **ровно** `src/lib/README.md`, а **не** корневой `./README.md` (который тоже существует).
3. Заполнить секцию Result с реальным evidence (какие изменения внесены, какие файлы изменены).
4. Отметить все пункты DoD как `[x]`.

## Шкала оценки (1–5)

Уровни — лестница по одному признаку: сначала выбран ли правильный файл, затем полнота Result. Сверяется хвост пути (`src/lib/README.md`): префикс рабочего каталога и имя каталога фикстуры значения не имеют.

| Балл | Описание |
|------|----------|
| **5** | Отредактирован файл из `context.files`, все пункты DoD отмечены `[x]`, Result содержит путь этого файла и конкретное описание внесённых изменений. |
| **4** | Отредактирован файл из `context.files`, все пункты DoD отмечены `[x]`, Result без описания изменений либо без пути файла. |
| **3** | Отредактирован файл из `context.files`, часть пунктов DoD не отмечена. |
| **2** | Отредактирован одноимённый файл из другой директории (корневой `README.md`). |
| **1** | Ни один файл не отредактирован. |
