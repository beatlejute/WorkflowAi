# Rubric: Декомпозитор соблюдает порог числа пунктов DoD (Проверка 5)

## Критерий

**Если задача плана требует больше 7 пунктов DoD в одном тикете, разбил ли агент тикет на 2+ атомарных тикета так, чтобы каждый результирующий тикет содержал ≤ 7 пунктов DoD? И привёл ли агент в выводе фактическое число пунктов DoD каждого созданного тикета (evidence Проверки 5)?**

Агент должен:
1. При декомпозиции задачи, естественно порождающей длинный DoD (8+ пунктов), распознать это на Проверке 5 и разбить тикет по группам независимых DoD-пунктов.
2. Ни один из финально созданных тикетов не должен содержать > 7 пунктов DoD (hard-порог `verify-atomicity.js` → иначе FAIL → повторный прогон декомпозиции → потеря 5-10 минут пайплайна).
3. Evidence-строка для Проверки 5 в inline-таблице должна содержать явное число пунктов DoD (например, «DoD содержит 5 пунктов, все проверяют создание компонента»), а не только «PASS».
4. Если исходная задача слита из независимых групп критериев — каждая группа → отдельный тикет со своим префиксом (если тип разный) или своим суффиксом/номером (если тип один).

## Шкала оценки (1–5)

Файлы созданных агентом тикетов в промпт судьи не попадают — судья видит вывод агента и только те тикеты, которые кейс подал входом. Поэтому число пунктов DoD в самих файлах проверяется механически (`verify-atomicity.js`), а шкала оценивает то, что агент сообщил в выводе.

Уровни — лестница по одному признаку: что вывод сообщает о числе пунктов DoD созданных тикетов. Ни один уровень не требует обнаружить превышение порога: задача, которой разбиение не понадобилось, получает балл по тому же признаку.

| Балл | Описание |
|------|----------|
| **5** | Тикеты созданы, для каждого из них вывод приводит число пунктов DoD, и ни одно число не больше 7. |
| **4** | Тикеты созданы, число пунктов DoD приведено не для каждого из них, и ни одно приведённое число не больше 7. |
| **3** | Тикеты созданы, числа пунктов DoD в выводе нет. |
| **2** | Тикеты созданы, и хотя бы для одного из них вывод приводит 8 и более пунктов DoD. |
| **1** | Тикеты не созданы — в том числе при остановке на входе или отказе, даже если вывод описывает будущее разбиение. |
