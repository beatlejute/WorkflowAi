# Rubric: Критерий без проверки в плане получает prose с причиной

## Критерий

**Какую запись проверки агент поставил под пунктом DoD критерия, у которого в плане нет строки «Проверка:»?**

Агент должен:
1. Распознать, что у критерия задачи плана нет строки «Проверка:», и не изобретать для него проверку командой (check) или изображением (visual).
2. Поставить под пунктом DoD вложенную запись prose с причиной «в плане нет проверки»: ревью и человек видят, что проверку не задал план, а не что агент счёл её невозможной.

## Шкала оценки (1–5)

Файлы созданных агентом тикетов в промпт судьи не попадают. Кейс просит агента привести секции DoD созданных тикетов в итоговом ответе, и шкала оценивает то, что показано там. Записи check и visual двух других критериев, дословность текстов критериев и форму записи под этим критерием — prose с непустой причиной — проверяет L1 кейса; скриптом не решается только то, о чём говорит причина.

Уровни — лестница по одному признаку: какая запись стоит под пунктом DoD критерия без проверки. Запись проверки — вложенная строка под пунктом, которая начинается с ключа check, prose или visual.

| Балл | Описание |
|------|----------|
| **5** | Под пунктом только запись prose с причиной `в плане нет проверки`. |
| **4** | Под пунктом только запись prose, и её причина другими словами говорит, что план проверку этому критерию не задал. |
| **3** | Под пунктом только запись prose с непустой причиной, которая об отсутствии проверки в плане не говорит. |
| **2** | Под пунктом нет записи проверки, стоит пустая prose или стоит запись check или visual — проверка, которой план не задавал. |
| **1** | В итоговом ответе нет пункта DoD с этим критерием — тикеты не созданы, стадия остановилась или секция DoD не приведена. |
