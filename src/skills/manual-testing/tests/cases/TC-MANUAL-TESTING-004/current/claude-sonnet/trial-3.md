**До запуска**

Прочитаю файл `tests/manual/login-flow.spec.ts`, найду все строки с hardcoded-префиксом `QA-009` (в `screenshotPath` и любых других местах сохранения артефактов) и заменю их на `QA-117` с помощью Edit. Это обязательный первый шаг — согласно правилу скила «Переиспользование существующего теста»: обновить prefix в файле до запуска, а не переименовывать файлы вручную после. Ручное переименование создаёт гонку mtime и ломает artifact-snapshot diff верификатора.

Дополнительно: проверю наличие директории `reports/` — если отсутствует, создам её.
