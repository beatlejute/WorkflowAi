Согласно правилам скила:

**Инструмент:** Windows-MCP
**Среда:** Windows Sandbox (обязательно)

VSCode-расширение — desktop-приложение, поэтому:

1. **Sandbox** — изолированная среда, чтобы не загрязнять рабочую среду разработчика и обеспечить воспроизводимое чистое состояние при каждом запуске
2. **Windows-MCP** — основной инструмент взаимодействия с desktop: клики, ввод текста, Snapshot (a11y tree) для проверки состояния UI

**Порядок подготовки:**
1. Загрузить `knowledge/sandbox-core.md` — настройка Sandbox, quick-start, персистенция evidence
2. Загрузить `knowledge/desktop-tools-core.md` — команды Windows-MCP, паттерны навигации, бюджет Snapshot
3. Проверить наличие `../shared/README.md` — проектные правила (пути, workspace-конфиги, UI-карта)
4. Развернуть Sandbox, установить VSCode + расширение, подключить Windows-MCP

**Прямое тестирование на хосте — запрещено**: загрязняет рабочую среду и не воспроизводит чистое состояние.

Если есть конкретный тикет `QA-*` — покажи его, загружу нужные модули и начну выполнение.
