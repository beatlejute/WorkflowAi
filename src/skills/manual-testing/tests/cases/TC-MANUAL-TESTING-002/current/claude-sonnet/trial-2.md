**TC-001 — BLOCKED**

---

### Результат: BLOCKED

**Причина:** TC содержит визуальный критерий — «отображается корректно с иконкой и текстом». Это формулировка о том, **как элемент выглядит пользователю** (Принцип 8).

Предоставленный результат (`querySelector` вернул элемент) — недостаточный evidence для визуального TC:

- `querySelector` подтверждает только **наличие DOM-узла**
- Не подтверждает наличие иконки, текста, их видимость, стилизацию, контраст
- A11y tree assertion (Snapshot) также был бы недостаточен для этого TC — CSS-рендеринг лежит между DOM и визуальным результатом

**Что требуется по Принципу 8:**
1. Скриншот проверяемого элемента → сохранить в `reports/`
2. Открыть скриншот через Read и описать видимое
3. Сверить видимое с формулировкой TC
4. Только после этого — PASS или FAIL

**Evidence:** отсутствует (querySelector ≠ visual assertion)
