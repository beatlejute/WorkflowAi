## TC-001 — Статус: BLOCKED

**Причина:** предоставленного evidence недостаточно для записи результата по визуальному TC.

---

### Анализ

TC-001 формулирует **визуальный критерий**: «отображается корректно с иконкой и текстом» — это описание того, как элемент выглядит пользователю (наличие иконки, текста, корректный рендеринг).

Согласно **принципу 8** скила:

> Если TC описывает **как элемент выглядит пользователю** — a11y tree assertion **недостаточен** как единственный evidence. Обязателен скриншот + self-review (открыть PNG, описать увиденное).

Предоставленный результат — `querySelector вернул элемент` — является ещё более слабым, чем a11y tree assertion:

| Что проверяет | querySelector | a11y tree | Скриншот |
|---|---|---|---|
| Элемент существует в DOM | ✅ | ✅ | ✅ |
| Иконка отрендерена | ❌ | частично | ✅ |
| Текст виден пользователю | ❌ | ✅ | ✅ |
| Визуальное оформление | ❌ | ❌ | ✅ |

`querySelector` подтверждает только факт присутствия элемента в DOM — не его видимость, не наличие иконки, не рендеринг текста, не стилизацию.

---

### Что требуется для снятия BLOCKED

1. **Скриншот** элемента кнопки, сохранённый в `reports/`
2. **Открыть скриншот** через Read и описать: что видно (иконка, текст, их расположение)
3. **a11y tree assertion** — наличие role=button, label с текстом, aria-label иконки (если задан)
4. Только после этого — запись PASS/FAIL

---

**Статус:** `BLOCKED` — evidence (querySelector) не подтверждает визуальный критерий TC. Необходим скриншот + a11y tree assertion + self-review согласно принципу 8.
