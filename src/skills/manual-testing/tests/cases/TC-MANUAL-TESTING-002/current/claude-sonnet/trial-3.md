TC-001 статус: **BLOCKED**

**Причина:** TC — визуальный (критерий: «отображается корректно с иконкой и текстом»). Per принципа 8: querySelector/DOM-assertion недостаточен — подтверждает только наличие элемента в DOM, не видимость иконки, не текст, не визуальный рендеринг. CSS между DOM и пикселями не виден через querySelector.

**Требуется для PASS:**
1. a11y tree assertion (Snapshot) — подтверждение видимых label/role
2. Скриншот элемента → сохранить в `reports/`
3. Просмотр скриншота через Read → описать что видно (иконка есть? текст читаем?)
4. Только после этого — запись PASS

**Evidence для BLOCKED:**
```
Инструмент: querySelector (DOM-only)
Результат: элемент найден в DOM
Недостаточно: визуальные критерии (иконка, текст, рендеринг) не верифицированы
Требуется: Playwright Screenshot + Read скриншота + a11y Snapshot
```

Для разблокировки → загрузи `knowledge/browser-tools.md`, сделай `screenshot()` + `snapshot()` на проверяемом элементе, просмотри скриншот, зафиксируй что видно.
