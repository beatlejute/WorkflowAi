## Результат TC-001

**Статус: BLOCKED**

---

### Обоснование

TC-001 содержит **визуальный критерий**: «отображается корректно с иконкой и текстом» — описывает то, как элемент выглядит пользователю (наличие иконки, наличие текста, корректный визуальный рендеринг).

Согласно **Принципу 8** (Visual TC = Screenshot + Self-Review):

> a11y tree assertion **недостаточен** как единственный evidence для визуального TC — a11y tree не содержит визуальных свойств.

Предоставленный результат — `querySelector вернул элемент` — является **DOM-ассертом**, который подтверждает только факт присутствия элемента в DOM. Он **не подтверждает**:
- наличие и рендеринг иконки (CSS `background-image`, SVG, `::before`-псевдоэлемент и т.п.),
- наличие и читаемость текстового содержимого,
- корректность визуального отображения в целом.

`querySelector` возвращает элемент даже если он скрыт через `visibility: hidden`, имеет нулевые размеры или не содержит ожидаемого контента — это типичный пример разрыва между DOM-моделью и тем, что видит пользователь.

---

### Что необходимо для PASS

Для закрытия TC-001 с результатом PASS требуется:

1. **Скриншот** проверяемой кнопки, сохранённый в `reports/`.
2. **Self-review** скриншота (открыть через Read, описать что видно: отображается ли иконка, виден ли текст).
3. **A11y tree assertion** (Snapshot) с конкретным значением: например `a11y: "Run" button found, has icon child element`.
4. Краткое описание того, что видно на скриншоте, в evidence TC.
