Source-of-truth файлы не найдены ни в одном из рабочих проектов — TC-XXX является шаблоном без привязки к конкретному проекту.

Ниже — описание процесса и структура test plan. **Имена пунктов меню и `when`-условия** оставлены как плейсхолдеры: их нельзя заполнить без реального source-of-truth.

---

## Процесс: с чего начинаю

**Шаг 1 — Открываю `product-ui-map.md`** (`.workflow/src/skills/shared/product-ui-map.md`)

Ищу: тип элемента основного списка (treeItem, listItem, и т.д.), его contextValue или идентификатор, ссылку на соответствующую секцию contributes.

Если файл отсутствует → перехожу сразу к шагу 2.

**Шаг 2 — Открываю корневой `package.json` расширения**

Читаю два раздела:

```json
"contributes": {
  "commands": [ ... ],   // title — это то, что видит пользователь в UI
  "menus": {
    "view/item/context": [ ... ]  // или "explorer/context", "editor/context"
  }
}
```

Для каждой записи в `menus` выписываю:
- `"command"` → ищу в `commands[]` соответствующий `"title"` — это **точное имя пункта в UI**
- `"when"` → условие видимости (contextValue, тип элемента, состояние флага)
- `"group"` → группа отображения (inline-кнопка или пункт контекстного меню)

**Шаг 3 — Формирую таблицу ожидаемых пунктов**

Каждая строка: command id → UI title → when → group → тип (inline / context).

Только после этого пишу test plan.

## Test Plan: TC-XXX — Контекстное меню элемента списка

**Предусловия для исполнителя:**
- Расширение установлено и активировано
- Список содержит хотя бы один элемент
- Записать: файл source-of-truth: `<путь к package.json>`, раздел `contributes.menus["view/item/context"]`

**Ожидаемые пункты меню** *(заполнить из `package.json` contributes)*:

| # | UI-заголовок пункта | Источник (file:line) | Условие видимости (`when`) | Тип |
|---|---------------------|-----------------------|----------------------------|-----|
| 1 | `[взять из commands[].title]` | `package.json:NNN` | `[взять из menus[].when]` | context / inline |
| … | … | … | … | … |

> **Инструкция исполнителю:** перед заполнением этой таблицы открой `package.json`, найди `contributes.menus` → раздел с нужным viewId. Для каждой записи найди соответствующий `command` в `contributes.commands` и возьми его `title` дословно. Пиши ровно то, что стоит в `"title"` — без правок регистра и пунктуации.

**Шаги воспроизведения:**

1. Открыть приложение, дождаться появления основного списка
2. Убедиться что список содержит элемент типа `[contextValue из source]`
3. Навести курсор на элемент — проверить inline-кнопки (если группа `inline`)
4. Нажать ПКМ на элемент — дождаться появления контекстного меню
5. Для каждого пункта из таблицы:
   - Проверить наличие / отсутствие пункта согласно `when`-условию
   - Записать точный текст видимого пункта
   - Сравнить с `title` из source (дословно)
6. Для пунктов с условием (`when` содержит contextValue): повторить тест с элементом другого типа и убедиться что пункт **не отображается**

**Evidence:**
- a11y tree Snapshot с открытым контекстным меню (текстовое подтверждение каждого пункта)
- Описание шагов с фактическими наблюдениями
