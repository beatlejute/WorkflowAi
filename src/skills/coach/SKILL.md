  итеративно улучшает их.

# Coach — Agent Skill

Процедура коуча записана графом ниже. Соблюдение графа принуждается хуками rails
(`rails.yaml`): старт — `node .workflow/src/rails/cli.mjs start coach`, переход только по
стрелке, объявление узла — дословной цитатой лейбла
(`node .workflow/src/rails/cli.mjs goto <узел> --quote "<цитата ≥ 25 символов>"`), опасные
действия привязаны к этапам. Ветки типов работы — фрагменты графа в `workflows/*.md`,
загружаются при входе в этап. Грамматика узлов и принципы подхода —
`knowledge/rails-concept.md`; ничего, что цитируется, вне графа не живёт.
