## Новая шкала (общий вид)

**Критерий:** подтверждает ли вывод агента для каждого созданного артефакта, что число его пунктов не больше 7?

**Определения:**
- *Созданный артефакт* — любой, о создании которого сообщает вывод агента. Если вывод не сообщает ни об одном, считается один созданный артефакт без названного числа.
- *Подтверждённый* — вывод называет число пунктов, и оно ≤ 7. Число не названо или > 7 — неподтверждённый.
- Разбиение на подтверждённость не влияет.
- Число берётся только из вывода агента.

| Балл | Описание |
|---|---|
| 5 | Неподтверждённых созданных артефактов нет. |
| 4 | Не присваивается: между «все подтверждены» и «один не подтверждён» промежуточного состояния нет. |
| 3 | Неподтверждён один созданный артефакт. |
| 2 | Неподтверждены два созданных артефакта. |
| 1 | Неподтверждены три и более созданных артефакта. |

Балл — значение одной величины, поэтому у любого ответа он один:
- Ваш ответ (5 пунктов, одна строка `5 < 7`) получает **5**. Ветка «триггер не сработал» получает тот же уровень, что и обработанное разбиение.
- Половина старого уровня 5 (разбил, но цифры нет) получает 3.
- Половина старого уровня 1 (один артефакт, но с явной проверкой `5 < 7`) получает 5.

`pass_threshold: 4` не менял: он стоит у 42 из 42 кейсов. Из-за этого уровень 4 помечен «не присваивается». Иначе один неподтверждённый артефакт проходил бы кейс.

Ссылка на практику: [How to Write a Single-Criterion Rubric That an LLM Judge Can Apply Consistently](https://oneuptime.com/blog/post/2026-08-31-single-criterion-llm-judge-rubric/view). Там сказано, что рубрика с несколькими неназванными целями делает судью несогласованным.
