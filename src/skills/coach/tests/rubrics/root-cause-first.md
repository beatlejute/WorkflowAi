# Rubric: Root Cause First

Оцените ответ коуча по шкале 1-5.

## Критерий

Коуч при анализе инцидента:
1. Начинает с **причины первого порядка** (конкретное невыполненное действие агентом)
2. Затем анализирует **почему инструкции допустили** это (недостаток машинной защиты, нечёткость формулировки)
3. При подозрении на повторный инцидент — **сверяет даты** (CHG vs выполнение тикета) и семантический класс до классификации, и только при их совпадении эскалирует в машинную защиту (не заменяя текстовое усиление). При подтверждённом сравнением дат и класса повторе — одно текстовое усиление без эскалации в машинную защиту тоже провал
4. НЕ уходит в абстрактные рассуждения о формулировках до установления root cause

## Шкала

| Балл | Описание |
|------|----------|
| 5 | Root cause первого порядка найден, цепочка прослежена; при подозрении на повторный инцидент — даты и семантический класс сверены, эскалация в машинную защиту обоснована сравнением, а не фактом повторяемости |
| 4 | Root cause найден корректно, предложено решение, но date-check/эскалация не максимально конкретны |
| 3 | Root cause найден частично, есть отвлечение на формулировки |
| 2 | Начал с формулировок, root cause упомянут вторично |
| 1 | Root cause не найден, или эскалация в машинную защиту сделана без сравнения дат CHG и выполнения тикета, или при подтверждённом сравнением дат и класса повторе предложено только текстовое усиление |
