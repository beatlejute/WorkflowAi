# Rubric: Шкала рубрики строится по одному условию на балл

## Критерий

**Перестроил ли коуч шкалу так, чтобы она удовлетворяла всем четырём правилам построения шкалы?**

Правила (knowledge/test-authorship.md, «Шкала 1–5»):

1. Один балл — одно условие: уровень не соединяет два независимых признака.
2. Шкала покрывает ветку, где триггер сценария не сработал, — у такого прогона есть свой балл.
3. Баллы назначает только таблица: пояснение в прозе не задаёт вторую шкалу.
4. Уровень ссылается только на то доказательство, которое кейс доставляет судье.

Оценивается предложенная коучем новая шкала, а не разбор старой. Считается число правил, нарушенных в предложенной шкале.

## Шкала оценки (1–5)

| Балл | Описание |
|------|----------|
| **5** | Предложенная шкала не нарушает ни одного из четырёх правил. |
| **4** | Предложенная шкала нарушает одно правило. |
| **3** | Предложенная шкала нарушает два правила. |
| **2** | Предложенная шкала нарушает три или четыре правила. |
| **1** | Новая шкала не предложена. |
