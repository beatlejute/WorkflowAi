# Алгоритм: Gap-анализ скила

Поиск пробелов в покрытии скила — что должно быть, но отсутствует.

## Вход

- Путь к директории скила
- Завершённые тикеты скила (из `.workflow/tickets/done/`)
- Планы и отчёты (если есть)

## Алгоритм

| Шаг | Что сравнивать | Ситуация | Тип пробела | Приоритет |
|-----|-----------------|----------|------------|-----------|
| 1. Маршрутизация vs реальные тикеты | Сравни типы из таблицы маршрутизации SKILL.md с типами реально пришедших тикетов | Тикет пришёл, воркфлоу нет | **Workflow Gap** | HIGH |
| 1. Маршрутизация vs реальные тикеты | | Воркфлоу есть, тикетов не было | Потенциально лишний | LOW |
| 1. Маршрутизация vs реальные тикеты | | Тикет не подошёл ни под один тип | **Routing Gap** | HIGH |
| 2. Знания vs потребности воркфлоу | Для каждого воркфлоу проверь: все ли данные, на которые он ссылается, есть в knowledge/? | Воркфлоу ссылается на несуществующий knowledge | **Knowledge Gap** | CRITICAL |
| 2. Знания vs потребности воркфлоу | | Воркфлоу требует данных, но не ссылается на knowledge | **Reference Gap** | MEDIUM |
| 2. Знания vs потребности воркфлоу | | Knowledge есть, но не используется ни в одном воркфлоу | Потенциально лишний | LOW |
| 3. Решения vs алгоритмы | Найди в воркфлоу места, где агент принимает решения. Есть ли для них формализованный алгоритм? | Решение принимается без алгоритма | **Algorithm Gap** | MEDIUM |
| 3. Решения vs алгоритмы | | Алгоритм есть, но не используется | **Adoption Gap** | MEDIUM |
| 4. Вывод vs шаблоны | Для каждого типа результата воркфлоу: есть ли шаблон в templates/? | Воркфлоу формирует результат без шаблона | **Template Gap** | MEDIUM |
| 4. Вывод vs шаблоны | | Шаблон есть, но не используется | Потенциально лишний | LOW |
| 5. Результаты тикетов | Изучи завершённые тикеты. Где результат неполный или низкого качества? | Пустые секции в результате | Воркфлоу неполный | HIGH |
| 5. Результаты тикетов | | Агент «придумал» данные | Нужен knowledge-модуль | HIGH |
| 5. Результаты тикетов | | Результат не по шаблону | Шаблон неизвестен агенту | MEDIUM |
