# Алгоритм: Оценка качества скила

## Вход

Путь к директории скила (`.workflow/src/skills/<name>/`).

## Алгоритм

Оцени скил по 5 категориям. Каждая категория — от 0 до 20 баллов. Итого максимум — 100.

| Категория (макс 20) | Критерий | Баллы |
|----------------------|----------|-------|
| 1. Структура | SKILL.md существует и содержит frontmatter | 4 |
| 1. Структура | README.md существует и описывает структуру | 4 |
| 1. Структура | workflows/ содержит файлы для каждого типа из маршрутизации | 4 |
| 1. Структура | knowledge/ содержит минимум 2 модуля | 4 |
| 1. Структура | algorithms/ содержит минимум 1 алгоритм | 2 |
| 1. Структура | templates/ содержит минимум 1 шаблон | 2 |
| 2. Полнота SKILL.md | Роль описана конкретно (делает / не делает) | 4 |
| 2. Полнота SKILL.md | Маршрутизация полная (все типы → воркфлоу) | 4 |
| 2. Полнота SKILL.md | Таблица загрузки knowledge заполнена | 3 |
| 2. Полнота SKILL.md | Таблица загрузки algorithms заполнена | 3 |
| 2. Полнота SKILL.md | Принципы конкретны и actionable (3–7 штук) | 3 |
| 2. Полнота SKILL.md | Формат вывода специфицирован | 2 |
| 2. Полнота SKILL.md | Границы компетенции определены | 1 |
| 3. Качество воркфлоу | Шаги пронумерованы и конкретны (глаголы) | 5 |
| 3. Качество воркфлоу | Ссылки на knowledge/algorithms где нужны данные | 5 |
| 3. Качество воркфлоу | Чеклисты / критерии завершения | 5 |
| 3. Качество воркфлоу | Нет дублирования между воркфлоу | 5 |
| 4. Качество знаний и алгоритмов | Knowledge структурирован (таблицы, категории) | 5 |
| 4. Качество знаний и алгоритмов | Маркеры расширения присутствуют | 3 |
| 4. Качество знаний и алгоритмов | Algorithms формализованы (формулы, пороги) | 5 |
| 4. Качество знаний и алгоритмов | Есть примеры применения | 4 |
| 4. Качество знаний и алгоритмов | Вход/выход алгоритмов определён | 3 |
| 5. Связность, консистентность, изоляция | Все ссылки из SKILL.md ведут на существующие файлы | 4 |
| 5. Связность, консистентность, изоляция | Все файлы knowledge/ упомянуты в таблице загрузки | 4 |
| 5. Связность, консистентность, изоляция | Все файлы algorithms/ упомянуты в таблице загрузки | 4 |
| 5. Связность, консистентность, изоляция | Терминология единообразна | 4 |
| 5. Связность, консистентность, изоляция | **Изоляция:** нет хардкода имён других скилов/ролей (grep на имена ролей = 0) | 4 |

## Выход

| Балл | Оценка | Рекомендация |
|------|--------|-------------|
| 80–100 | **EXCELLENT** | Скил готов к работе, мелкие улучшения |
| 60–79 | **GOOD** | Работоспособен, но есть существенные пробелы |
| 40–59 | **NEEDS_WORK** | Требуется серьёзная доработка |
| 0–39 | **POOR** | Фундаментальные проблемы, рассмотреть пересоздание |

## Пример

`example-skill`: структура 20 + полнота 20 + воркфлоу 18 (−2 неполные чеклисты) + знания 17 (−3 нет примеров в algorithms) + связность 20 = **95/100 — EXCELLENT**
