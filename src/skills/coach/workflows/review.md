# Воркфлоу: REVIEW — Ревью скила

Быстрое ревью структуры и качества скила с фокусом на конкретные аспекты.

## Алгоритм выполнения

### 1. Определи фокус ревью

Из тикета извлеки: какой аспект проверить?

| Фокус | Что проверять |
|-------|--------------|
| **Структура** | Полнота директорий и файлов, ссылочная целостность |
| **Качество промптов** | Чёткость инструкций, отсутствие двусмысленности |
| **Покрытие** | Все ли сценарии обработаны, нет ли пробелов |
| **Консистентность** | Единообразие терминов, форматов, стиля |
| **Актуальность** | Не устарели ли знания, бенчмарки, инструменты |

Если фокус не указан — проведи ревью по всем аспектам.

### 2. Чтение и анализ

Прочитай все файлы скила; чеклист по типам файлов → `knowledge/skill-anatomy.md` «SKILL.md — обязательные секции» и «Требования к качеству компонентов». Дополнительно для SKILL.md: RACI чёткий (если применимо); для Workflows: нет дублирования между воркфлоу.

### 3. Формирование замечаний

Для каждого замечания укажи, а затем исправь скил по найденным недостаткам (см. `SKILL.md` → «Результат работы коуча»):
- **Файл и секция** — где проблема
- **Приоритет** — CRITICAL / HIGH / MEDIUM / LOW
- **Проблема** — что не так
- **Рекомендация** — как исправить

### 4. Тест → `workflows/test.md`

Если ревью привело к правке скила — создай регрессионный тест, фиксирующий находку → `workflows/test.md` (шаги 1-9), сообщи verdict и затронутые файлы по шагу 8 test.md, остановись.
