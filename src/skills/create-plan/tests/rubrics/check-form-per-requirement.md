# Rubric: у каждого требования ТЗ — запись проверки подходящей формы

## Критерий

**Получило ли каждое из трёх требований входного документа запись подходящей формы в строках «Проверка:», приведённых в ответе?**

У каждого требования входного документа кейса одна подходящая форма записи (шаблон плана, узел P10S7 скила):

- команда `node scripts/summary.js --month 2026-09` печатает строку `Итого: <сумма> ₽` — `check: …, expect: …` без пометки `regression`;
- подпись под суммой понятна пользователю без финансовой подготовки — `prose: …` с непустой причиной, почему командой не проверить;
- карточка со сводкой стоит над таблицей расходов и не перекрывает её заголовок на ширине 360 px — `visual: …` с путём или маской изображения.

Запись относится к требованию, если стоит в строке «Проверка:» задачи, которую ответ называет закрывающей это требование (кейс просит у каждой задачи номера требований 1–3). Требование получило подходящую форму, если среди записей таких задач есть запись этой формы; записи других форм рядом с ней этого не отменяют. Требование, которое ответ не относит ни к одной задаче, или без записи подходящей формы подходящей формы не получило.

Файл плана в промпт судьи не попадает: судья видит итоговый ответ, в котором кейс просит у каждой задачи номера закрываемых требований и строку «Проверка:» дословно из сохранённого файла. Шкала оценивает то, что приведено в ответе.

## Шкала оценки (1–5)

Уровни — лестница по одному признаку: сколько из трёх требований получили запись подходящей формы. Ответ без записей проверки — отдельный уровень.

| Балл | Описание |
|------|----------|
| **5** | Запись подходящей формы получили все три требования. |
| **4** | Запись подходящей формы получили два требования из трёх. |
| **3** | Запись подходящей формы получило одно требование из трёх. |
| **2** | Ни одно из трёх требований не получило запись подходящей формы, хотя записи проверки в ответе приведены. |
| **1** | Записей проверки задач в ответе нет — план не создан, агент остановился или строки «Проверка:» не привёл. |
