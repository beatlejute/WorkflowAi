# Analyze Report — Agent Skill

Аналитик отчётов для workflow-ai. Анализирует отчёты о выполненных задачах, оценивает прогресс по планам, проводит ретроспективы и формирует actionable рекомендации. Скил на рельсах: процедура — граф в `SKILL.md` и `workflows/*.md`, соблюдение принуждают хуки по `rails.yaml`.

## Структура

```
analyze-report/
├── SKILL.md                              # Ядро: граф П0 (вход, правила, маршрутизация), П3 (отчёт), П5 (самопроверка), П6 (---RESULT---)
├── rails.yaml                            # Гарды: запись плана, выходной слой, потолки, канарейка
├── rails-migration.yaml                  # Карта переноса прозы в граф (покрытие инвариантов)
├── README.md                             # Документация
├── workflows/
│   ├── progress.md                       # Фрагмент графа П10: оценка прогресса по плану
│   └── retrospective.md                  # Фрагмент графа П20: ретроспектива завершённого плана
├── knowledge/
│   ├── analysis-frameworks.md            # Методологии анализа, метрики, паттерны
│   └── report-structure.md               # Структура отчётов, правила извлечения данных
├── algorithms/
│   └── progress-assessment.md            # Алгоритм оценки прогресса (формулы, пороги)
├── templates/
│   └── analysis-report.md                # Шаблон результата анализа
├── scripts/
│   └── calc-plan-metrics.js              # Метрики плана из тикетов
└── tests/
    ├── cases/, rubrics/, fixtures/       # Регрессионные тесты L0/L1/L2
    └── rails/                            # Тесты гардов rails
```

## Как это работает

1. Стадия пайплайна или тикет `ANL-*` запускает скил; раннер создаёт состояние рельс в узле P0E1.
2. Агент проходит граф: вход и правила (П0), выбор ветки PROGRESS или RETROSPECTIVE (P0Q1).
3. Ветка собирает данные, считает метрики, верифицирует проблемы по логу пайплайна.
4. Отчёт по шаблону (П3), валидация ветки, самопроверка (П5).
5. Финальный ответ кончается блоком `---RESULT---` со status `completed` или `has_gaps` (П6); хук выходного слоя проверяет формат и положение в графе.

## Как расширять

Правки скила — только через коуча на рельсах (IMPROVE), с тест-кейсом и проверками:
`node .workflow/src/scripts/check-rails-graph.js --skill analyze-report` и
`node .workflow/src/scripts/check-rails-coverage.js --skill analyze-report --baseline <ref>`.

- **Новый тип анализа** — фрагмент `workflows/{type}.md` с этапом П30, П40, … и ребро из `P0Q1`.
- **Новый knowledge-модуль или алгоритм** — файл в `knowledge/` или `algorithms/` и узел графа с условием загрузки.
- **Новый шаблон вывода** — файл в `templates/` и ссылка в узле этапа отчёта.
- **Новый гард** — только по инциденту с датой и ценой: запись в `rails.yaml` и тест в `tests/rails/`; включает человек.
