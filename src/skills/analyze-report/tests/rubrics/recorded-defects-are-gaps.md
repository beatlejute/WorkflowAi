# Rubric: Исход записанного дефекта

## Критерий
Верно ли определён исход каждой записи о дефекте по доставленным доказательствам?

## Доставленное доказательство
Синтетический сценарий, не исторический факт. PLAN-S010: T25 — гео-блок; T2 — TikTok; T3 — модалка; T4 — старый значок; T5 — popup.

A: QA-S010-A, archive, T25, 30 сентября, check green, подраздела дефектов нет. Заметка: «Найденный дефект: title при гео-блоке НЕ равен geoBlockedTitle». Исполнитель: известный баг, в следующий план. FIX-S010-A в backlog, исправление не записано.

B: HUMAN-S010-B, done, T2, 30 сентября, подраздела дефектов нет. Результат: «TikTok-сценарий не работает». Исполнитель: вне скоупа. Исключения плана или решения стейкхолдера нет.

C: QA-S010-C, done, T3: «**Дефектов не обнаружено.**».

D: QA-S010-D, done, T3, 29 сентября: «Модалка не открывается». FIX-S010-D, done, 1 октября: «Исправлен дефект QA-S010-D: модалка открывается, проверка PASS». Повторной находки позже нет.

E: QA-S010-E, done, T4: «Старый значок не меняет цвет». План исключает «Исправление цвета старого значка» в разделе «Исключено из scope».

## Ось оценки
N — количество записей A–F, для которых финальный ответ доказал корректный исход по соответствующей записи. Противоречащее себе решение не засчитывается. Для каждого элемента требуется единое решение со своим основанием, а не буквальное совпадение слов.

- A: gap по T25 из цитаты QA-S010-A; green, отсутствие подраздела, слова исполнителя и существование backlog-FIX не выдаются за исправление.
- B: gap по T2 из результата HUMAN-S010-B; слова исполнителя о скоупе не выдаются за полномочное исключение.
- C: запись об отсутствии дефектов, не находка и не gap, с опорой на цитату QA-S010-C.
- D: находка снята именно более поздним записанным исправлением FIX-S010-D, не остаётся gap.
- E: рекомендация, не gap и не исправленный продукт; основание — цитата исключения плана.
- F: рекомендация с переносом в PLAN-S011, не gap и не исправленный продукт; основание — записанное решение стейкхолдера.

Решения A/B засчитываются только если они переданы в итоговый gaps при status has_gaps. Это часть исхода находки, а не отдельная ось оформления. Оценивай только финальный ответ по snapshot, не инструменты и не созданные файлы. Синонимы допустимы.
