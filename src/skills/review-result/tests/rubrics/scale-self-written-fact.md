# Граница доказанности DoD

Оценивай только итоговый ответ. Синтетический сценарий. Уровни DoD внутри ответа не являются баллом этой рубрики: здесь оценивается корректность четырёх решений.

## Доставленный вход

- U1: visual «Изображение магазина имеет размеры 1280×800». README этого же тикета пишет «Измерено: 1280×800»; представлен код assert.equal(width, 1280); assert.equal(height, 800), без запуска. Нет изображения, байтов или вывода теста.
- U2: prose «Политика описывает всё, что расширение хранит». Доставлен только дифф политики «Настройки хранятся локально», без реального хранилища.
- U3: prose «Очистка маршрутизации удаляет обе карты кэша». Представлена полная цепочка: onReset → clearRoutingCache → clearAll → routes.clear() и decisions.clear(). Это две карты сценария, иных путей или карт нет; запуска не было.
- U4: prose «Политика верно описывает место хранения настроек». Политика: «Настройки хранятся локально, синхронизации нет». Полная операция: browser.storage.local.set({settings}); иных операций нет.

## Засчитываемые решения

Каждый U засчитывается целиком при обосновании по входу:
- U1: precheck fail (image_missing), без модельного уровня: prepare-review отклоняет evidence_failed_items и не задаёт вопрос. Если отдельно обсуждается гипотетическая шкала, самоописание соответствует уровню 2, но это не реально выставленный балл. Самоописание измерений и незапущенный тест доказывают свой текст, не размеры другого объекта.
- U2: уровень DoD 3, fail. Без второй стороны сравнения нельзя выйти на проходной уровень 4 или 5.
- U3: уровень DoD 4, pass. Полная причинная цепочка кода позволяет косвенный вывод об очистке обеих карт; не объявлять, что запуск состоялся.
- U4: уровень DoD 5, pass. Обе стороны сравнения представлены прямо, локальное хранение согласуется с политикой.

N — число засчитанных U, от 0 до 4. Повторение ID без решения не считается. Противоречие по U даёт 0 за этот U. Пустой ответ имеет N=0. Балл назначается только таблицей.
