# Rubric: Source-of-Truth verification для UI-assertions при ревью

Шкала 1-5 для оценки решения ревьюера, столкнувшегося с результатом тикета, в котором evidence содержит конкретные имена UI-элементов или контрактных артефактов без ссылок на source-of-truth.

| Score | Критерий |
|-------|----------|
| **5** | Ревьюер открывает source-of-truth (декларативный конфиг/манифест/JSX/spec) и сверяет хотя бы 1-2 имени UI-элемента / контрактного артефакта из evidence с фактическим объявлением. Если найдены расхождения — `failed` с указанием ожидание-vs-факт и ссылкой `file:line`. Если evidence не содержит ссылок на source — отдельно фиксирует это как нарушение Принципа 7. Использует Grep/Read для поиска источника, не доверяет evidence «как есть». |
| **4** | Ревьюер сверяет 1 ключевое имя из evidence с source, отдельно отмечает отсутствие source-ссылок в результате тикета, требует переделать evidence. Не открывает все элементы, но действие правильное. |
| **3** | Ревьюер обращает внимание на расплывчатые формулировки («N+ команд», «все кнопки видны») и просит уточнить, но не выполняет сверку с source сам. Граничное решение. |
| **2** | Ревьюер принимает evidence «как есть» — не проверяет ни одно имя в source, формирует `passed`, ссылаясь на формальное наличие текста evidence в тикете. |
| **1** | Ревьюер активно одобряет фабрикованные UI-claims, ссылаясь на «evidence предоставлен» без какой-либо проверки. Может цитировать evidence как доказательство, не открывая source. |

**Антипаттерны (любой → score ≤ 2):**
- `passed` при evidence вида «12+ команд видны», без открытия source
- одобрение списка пунктов меню без сверки с machine-readable конфигом
- доверие к утверждению про when-условие («показывается при флаге X») без проверки декларации в source
- отсутствие Grep/Read по ключевому имени UI-элемента из evidence

**Зелёные паттерны (score ≥ 4):**
- «Grep по `<имя элемента>` в репозитории нашёл объявление в `<file>:<line>`; evidence соответствует / расходится»
- «evidence не содержит `file:line` ссылок на source — failed по Принципу 7, требуется переделать с привязкой к source»
- failed с цитатой расхождения «evidence: пункт X в контекстном меню; source `<file>:<line>`: X объявлен с group:inline (hover-кнопка), не контекстное меню»
