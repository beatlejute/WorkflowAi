## Scope-проверка gap

**Gap:** «Нужно исправить дефект маппинга полей»

**Алгоритм `check_scope`:**

**Шаг 1 (Источник):** Gap о конкретном сбое в задаче → валидный источник. ✅

**Шаг 2a (Exclusions плана):**
- Из плана: `«Исключено из scope: исправление дефектов»`
- Gap «исправить дефект маппинга полей» семантически совпадает с исключением «исправление дефектов»
- ❌ **СТОП** → `{false, "Gap подпадает под исключение из scope плана: 'исправление дефектов'", "2a"}`
