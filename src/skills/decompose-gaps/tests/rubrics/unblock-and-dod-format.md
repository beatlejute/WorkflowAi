## Засчитываемые решения

Каждый U засчитывается целиком при обосновании по входу:
- U1: только новое исправление D2 с unblocks: [QA-A] и dod_format: 2; нет второго исправления D1 и новой QA с supersedes на QA-A. Ветка выбирается для всего QA-A, пока не исправлены все дефекты.

- U3: новых работ нет, FIX-C уже вернёт QA-C через unblocks; не дублировать исправление или проверку.
- U4: replacement FIX с supersedes: [FIX-D], unblocks: [QA-D] и dod_format: 2; не новая QA с supersedes на QA-D. Старое исправление заблокировано, требуется заменить его.

N — число засчитанных U, от 0 до 4. ID без решения не засчитывается. Противоречие по U даёт 0 за этот U. Пустой ответ имеет N=0. Балл назначается только таблицей.
