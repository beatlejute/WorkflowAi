### Executive Summary

Manifest V3 поддерживает стандартные веб-форматы (JS, HTML, CSS, JSON) для кода и конфига, изображения (PNG, JPEG, SVG, WebP) для UI-ассетов, и JSON для локализации. Точный список поддерживаемых MIME-типов и расширений требует проверки официальной документации Google Chrome [данные не найдены].

### Ключевые находки

1. **JavaScript** — единственный скриптовый язык для логики расширения [данные не найдены]

2. **Web Accessible Resources** — файлы, доступные веб-контексту, должны быть явно декларированы в `manifest.json` → `web_accessible_resources` [данные не найдены]

3. **Service Worker вместо Background Page** — в V3 нет `background.html`, только `.js` с обработчиком `service_worker` [данные не найдены]

4. **Manifest.json структура** — обязательный файл, определяет все остальные ресурсы и их типы [данные не найдены]

5. **Локализация** — JSON-файлы в папке `_locales/{locale}/messages.json` [данные не найдены]
